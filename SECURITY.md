# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

If you believe you have found a security issue, please **do not** open a public issue.

Email or contact the maintainer via [GitHub](https://github.com/ludioo) with:

- A description of the issue
- Steps to reproduce
- Unity version and package version (if known)

You should receive a response within a reasonable timeframe. Public disclosure should wait until
the issue is reviewed.

## Scope note

Project Health Check is a read-only Unity Editor tool. It does not execute untrusted code, connect
to external services, or modify project assets. Most reports are likely to be bug reports rather
than security vulnerabilities — those can be filed as regular [issues](https://github.com/ludioo/Unity-Project-Health-Check/issues).
