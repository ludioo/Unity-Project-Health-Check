**Project Health Check for Unity — Early MVP**

I built a read-only Unity Editor tool that scans your project for common health issues:

- Missing scripts
- Oversized textures
- Large files
- Invalid build scenes
- Empty folders

Open **Tools → Project Health Check**, hit **Scan Project**, and ping affected assets. It does not modify your project.

Requires Unity 2022.3 LTS+ and Git.

Install via Package Manager → Add package from git URL:

```
https://github.com/ludioo/Unity-Project-Health-Check.git?path=/Packages/com.ludioo.project-health-check#v0.1.2
```

GitHub: https://github.com/ludioo/Unity-Project-Health-Check

This is an early MVP — feedback welcome. Try it and open an issue with bugs or ideas.
