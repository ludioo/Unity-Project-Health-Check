# Project Health Check

Project Health Check is an Editor-only Unity package for detecting missing scripts, oversized
textures, large files, invalid build scenes, and empty folders.

Open **Tools > Project Health Check**, expand **Scan Settings** when custom thresholds are needed,
and select **Scan Project**. The scan is manual, read-only, and limited to the project's `Assets`
folder. The responsive UI Toolkit window summarizes and groups results by check, supports category
filtering, and can select and ping related assets.

Requires Unity 2022.3 LTS or newer.
